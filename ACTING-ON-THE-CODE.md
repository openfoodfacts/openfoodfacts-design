# Acting on the Code

This document provides quick links to the key code locations for implementing design changes across Open Food Facts products.

## Server (Website)
- CSS: https://github.com/openfoodfacts/openfoodfacts-server/tree/main/scss
- Templates: https://github.com/openfoodfacts/openfoodfacts-server/tree/main/templates
- Icons: https://github.com/openfoodfacts/openfoodfacts-server/tree/main/icons — many sourced from [Google Material Symbols and Icons](https://fonts.google.com/icons), plus custom icons by [@stephanegigandet](https://github.com/stephanegigandet)

## Mobile App (smooth-app)
- Source: https://github.com/openfoodfacts/smooth-app
- Food Icons (foodicons) — a handcrafted icon font by [@g123k](https://github.com/g123k): https://github.com/openfoodfacts/smooth-app/tree/develop/packages/smooth_app/assets/fonts
- Other assets (images, etc.): https://github.com/openfoodfacts/smooth-app/tree/develop/packages/smooth_app/assets
